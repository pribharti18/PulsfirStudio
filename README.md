# PulseFit Studio — Responsive Fitness Landing Page

A modern, mobile-first landing page for a fitness studio built using **HTML5, CSS3, and JavaScript**. It features responsive layouts, an interactive monthly/quarterly plan toggle, an FAQ accordion, and a mobile navigation drawer.

## Live Demo
- **Live Page:** `https://pribharti18.github.io/pulsefit-landing/`
- **Repository:** `https://github.com/pribharti18/pulsefit-landing`

## Key Features
- Responsive navigation bar with mobile menu drawer
- Program showcase cards and trial booking call-to-actions
- Interactive monthly vs. quarterly pricing toggle
- Expandable FAQ accordion for smooth reading

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid & Media Queries)
- Vanilla JavaScript

## How to Run Locally
1. Download or clone the repository.
2. Open `index.html` in your web browser.
